# 微博批量取消「非互关」关注

一个在**浏览器控制台**运行的脚本，用于批量取消微博中「**对方没有回关我**」的关注关系。
纯前端运行，不依赖任何第三方服务器，不上传你的账号信息。

## 功能

- 自动读取你的关注列表
- 筛选出「非互关」（单向关注）的账号
- 逐个取消关注，带随机间隔以降低触发风控的概率
- 自动循环，直到所有非互关清完为止

## 使用方法

1. 浏览器登录 <https://weibo.com>，并打开你自己的个人主页
2. 按 `F12` 打开开发者工具，切换到 **Console**（控制台）
3. 复制 `weibo-unfollow.js` 的全部内容，粘贴到 Console，回车
4. 弹出确认框，确认后开始执行
5. 等待完成，Console 会显示实时进度与最终统计

> 若浏览器首次阻止粘贴：按提示在 Console 里输入 `allow pasting` 回车后，再重新粘贴。
> 也可以用开发者工具的 **Sources → Snippets** 新建片段粘贴运行，不受粘贴限制。

## 参数说明

脚本顶部「可调参数」区域：

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `DELAY_MIN` / `DELAY_MAX` | 两次取消之间的随机间隔（毫秒），不建议低于 1000 | 1800 / 3500 |
| `MAX_ROUNDS` | 最多循环轮数（安全上限） | 800 |
| `MAX_PAGES` | 每轮最多抓取页数 | 100 |

## 注意事项

- ⚠️ 取消关注**不可撤销**，请确认后再运行
- ⚠️ 微博对批量操作有风控限制，请**保持间隔、分批操作**；若某轮开始大量失败，说明可能被限流，请暂停后隔一段时间再试
- 脚本依赖微博网页端接口，若官方接口变更可能失效
- 仅供**管理自己的账号**使用

## 原理

- 读取关注列表：`GET /ajax/profile/followContent`
- 取消关注：`POST /ajax/friendships/destory`（注意官方接口的拼写就是 `destory`，不是 `destroy`）
- 写操作需携带 `x-xsrf-token`（取自 Cookie `XSRF-TOKEN`）

## 常见问题

**Q：跑完关注数没变？**
A：以「关注列表里实际剩几个」为准。页面顶部的关注数是带缓存的，延迟更新，刷新或等一段时间会自行纠正。

**Q：一次只取消了一小批？**
A：脚本会循环多轮，列表滚动后继续处理，直到没有非互关为止。
